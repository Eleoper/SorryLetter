# SorryLetter

A one-page apology site: a hand-drawn bouquet that blooms on load (tap it to add flowers), a sealed envelope that opens into a handwritten letter, and a gentle "Can you forgive me?" at the end.

Everything lives in `index.html`. There's no build step and nothing to install.

## View it

- Open `index.html` in any browser, or
- Host it with GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**. The site will appear at `https://<username>.github.io/<repo-name>/`.

## Edit the letter

The letter text is in `index.html` inside `<div class="note">`. Each `<p>` is one paragraph.
